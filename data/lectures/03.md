# Lecture 03 AI Agents

## Aims

- Understand that an AI agent's basic structure is "model + loop + tools"
- Build and run your own learning support agent that uses tools with Pydantic AI

## Key Points

1. **What is an agent?**: A system that achieves a goal through a loop in which an LLM calls tools, examines the results, and decides its next action.
2. **Tools**: The model looks at tool names, descriptions, and argument types to request a call, while the program executes it. Description wording changes behavior.
3. **Cost of the agent loop**: Multiple LLM calls for one question have a substantial effect on response time, charges, and rate limits.
4. **Harness**: A program such as Claude Code or Pi that wraps an LLM with a loop, tools, and a UI. Pi is a thin harness with just four built-in tools (read, write, edit, bash).
5. **Frameworks**: Pydantic AI (the main framework here) defines tools and outputs with types and supports checking behavior without API calls using a test model (TestModel). ADK is Google's agent development framework.
6. **Guardrails and Human-in-the-loop**: For operations that are hard to undo, such as writes, restrict permissions or request human confirmation.
