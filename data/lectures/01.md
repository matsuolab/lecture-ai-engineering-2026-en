# Lecture 01 Introduction to AI Engineering and the Development Environment

## Aims

- Understand that AI engineering focuses on "using models as components and iterating on evaluation and improvement" rather than "building models"
- Get hands-on experience with the development environment used throughout the course (GitHub Codespaces, GitHub Copilot, Gemini API)

## Key Points

1. **What is AI engineering?**: Turning pretrained LLMs into useful systems by using them as components, connecting them to data and tools, and improving them through evaluation.
2. **LLM basics**: Input is split into tokens, and text is generated by predicting subsequent tokens. Outputs vary probabilistically (temperature). Models can give plausible answers about things they do not know (hallucination).
3. **Using an API**: Call the Gemini API from Python. API keys are secrets: register them as Codespaces secrets and read them through the GEMINI_API_KEY environment variable. Do not put them in code.
4. **Development environment**: Codespaces creates a cloud environment according to the repository's configuration (devcontainer). Stop it when you finish.
5. **AI coding**: Write code with Copilot completion and chat. Read and understand suggestions before accepting them.
6. **Submission process**: Fork the course repository → work on a branch for the session → fill in lectures/NN/answer.md → open a PR to main in your own fork.
